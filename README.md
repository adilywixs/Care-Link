# CARE LINK — Every Patient. Every Second.

Demo website with a working hospital monitoring dashboard (synthetic data).
Демо-сайт с рабочей системой мониторинга пациентов (синтетические данные).
Демо-сайт: науқастарды бақылау жүйесі (синтетикалық деректер).

## Languages
English, Русский, Қазақша (switcher in the top bar).

## What is inside
- Public pages: Home (animated intro), How It Works, Technology, Contact / Pilot request
- Monitoring system: Dashboard, Patient Monitoring, Patient Profile, Alert Center, Analytics, Devices, Notifications, Settings
- Live simulation of 40 synthetic patients, 4 alert scenarios (elevated heart rate, low SpO2, possible fall, device disconnected)
- Some patients start yellow ("attention"), the rest are stable
- Sound alerts, acknowledgment, search, filters, sorting, grid/list views

## Run
One static file. Open `index.html` in a browser. No build, no backend.

## GitHub Pages
Repository -> Settings -> Pages -> Deploy from a branch -> `main` / root.

## Disclaimer
CARE LINK is a demonstration prototype using synthetic patient data. It is not intended for clinical use, medical diagnosis, or emergency response. Demonstration thresholds and scenarios are illustrative only. Real-world deployment would require medical validation, regulatory compliance, device integration, and clinical testing.
