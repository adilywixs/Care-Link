# CARE LINK — Every Patient. Every Second.

**Официальный сайт-визитка и интерактивная демонстрационная платформа B2B MedTech SaaS решения для круглосуточного мониторинга пациентов в стационарах.**

> **Презентационный лендинг:** автономный, сверхбыстрый статический сайт без зависимостей и сборщиков. Работает напрямую в браузере через `index.html` и идеально подходит для деплоя на **GitHub Pages**, **Vercel** или любой CDN.

---

## 🌟 Ключевые разделы сайта-визитки

1. **Главный экран (Hero Section):**
   - УТП продукта: непрерывная телеметрия с умных браслетов для обычных отделений и палат интенсивной терапии.
   - Живой интерактивный кардио-виджет с отображением ЭКГ-волны, ЧСС, сатурации SpO₂ и статуса стабильности в реальном времени.
   - Быстрые целевые действия (CTA): запуск демо-песочницы, заявка на пилотное внедрение, повтор интро.

2. **Клиническая ценность (Проблема vs Решение):**
   - Наглядное сравнение классической практики замеров (раз в 4–6 часов, ночные кризы, синдром усталости от тревог) и преимуществ непрерывной телеметрии Care-Link.

3. **Возможности платформы:**
   - Централизованный пульт поста медсестры (до 40+ коек на одном экране).
   - Интеллектуальный детектор падений на базе 6-осевого акселерометра и гироскопа.
   - Аудиовизуальные контекстные тревоги с обязательным квитированием (Acknowledge) для контроля дисциплины смены.
   - Управление парком носимых IoT-браслетов (BLE Mesh, уровень батареи, статус связи).
   - Поддержка интеграции с МИС (HL7 / FHIR API).

4. **Интерактивная демо-песочница (Live Telemetry Sandbox):**
   - Полноценная живая модель отделения на 40 коек с автоматическим расчётом трендов и нормальным дрейфом показателей.
   - Моделирование 4 критических сценариев ЧП:
     - ⚡ Острая тахикардия (ЧСС > 130)
     - 📉 Опасная гипоксия (SpO₂ < 90%)
     - 🚨 Падение пациента (удар 3.8G + неподвижность)
     - 🔌 Обрыв радиосвязи браслета
   - Аудио-синтезатор клинических сигналов тревоги через Web Audio API.
   - Просмотр детального диагностического профиля пациента по клику на карточку.

5. **Полноэкранная рабочая станция поста медсестры (Clinical Workstation):**
   - Доступ по кнопке **«Станция медсестры»** или из песочницы.
   - Вкладки: *Сводка по отделению*, *Журнал мониторинга*, *Центр тревог*, *Аналитика*, *IoT-устройства*, *Настройки*.
   - Легкий возврат на презентационный сайт-визитку в один клик.

6. **Архитектура и интеграция:**
   - 4-уровневый контур: Датчик на запястье → Шлюз палаты → SaaS-ядро анализа → Экран поста медсестры.
   - Спецификации оборудования (IP68, влагозащита, 7 дней автономности, быстрая санобработка).
   - Безопасность: сквозное шифрование AES-256, соответствие HIPAA/GDPR.

7. **Тарифы и пилотное внедрение:**
   - Бесплатный пилотный проект на 30 дней (до 15 коек).
   - Тариф для профильного отделения (20–80 коек).
   - Госпитальная сеть (Enterprise) с интеграцией с МИС и On-Premise развертыванием.

8. **Интерактивная форма заявки на пилот:**
   - Валидация полей, профили отделений, мгновенная обратная связь с уведомлением.

9. **FAQ и Мультиязычность:**
   - Аккордеон с частыми вопросами главврачей и администраторов.
   - Полная поддержка 3 языков: **Русский (RU)**, **English (EN)**, **Қазақша (ҚАЗ)** с переключением на лету.
   - Тёмная и светлая темы оформления.

## 🚀 Запуск и деплой

### Локальный запуск
Никаких `npm install` или сборщиков не требуется.
Просто откройте файл `index.html` в любом современном браузере:
- Дважды кликните по `index.html`, либо
- Запустите локальный сервер (например, `npx serve .` или `vercel dev`).

Для работы живого **Groq AI Триажа (`qwen/qwen3.8-27b`)**:
- В **Vercel** настройте переменную окружения `GROQ_API_KEY`, чтобы серверлесс-прокси `api/triage.js` выполнял защищённые серверные запросы без раскрытия ключа на клиенте.
- При локальном запуске статического файла доступен опциональный ввод BYOK-ключа в окне диагностики AI (хранится только в `sessionStorage`), а без ключа платформа автоматически использует детерминированный клинический протокол fallback.

### Публикация на GitHub Pages
1. В репозитории перейдите в **Settings** → **Pages**.
2. В секции **Build and deployment** выберите Source: `Deploy from a branch`.
3. Укажите ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Сайт будет доступен по адресу: `https://<ваш-логин>.github.io/Care-Link/`
